# Colab 노트북 Python 변환본

이 폴더는 모듈화 전 단계의 변환본입니다. 원본 7개 노트북의 코드 셀 순서와 실험 설정을 유지합니다. 노트북은 수정하지 않습니다. import만으로 학습, 평가, 업로드를 실행하지 않습니다.

| 파일 | 원본 작업 |
| --- | --- |
| train.py | OpenFedLLM 학습 |
| inference.py | 어댑터 및 베이스 모델 추론 |
| evaluate.py | 답변 평가 |
| analyze_results.py | CSV 집계와 차트 |
| upload_dataset.py | 데이터셋 업로드 |
| upload_adapters.py | 어댑터 업로드 |
| demo_adapter.py | 어댑터 추론 시연 |

## 변환 내용

- Colab 드라이브 마운트를 제거했습니다.
- 두 가지 기존 Drive 프로젝트 경로를 현재 프로젝트 루트로 바꿨습니다. 다른 위치는 `FL_FRAMEWORK_ROOT` 환경변수로 지정할 수 있습니다.
- Colab 시크릿 조회를 `HF_TOKEN` 환경변수 조회로 바꿨습니다. API 평가용 키 파일은 기존 FLASK 설정을 사용합니다.
- `!python`, `!bash` 명령은 셸 없이 subprocess로 호출합니다. Python 명령은 현재 인터프리터를 사용합니다.
- pip 설치 셀은 자동 실행에서 제외했습니다. 기존 설치 명령은 원본 노트북에 남아 있습니다. 환경 통합은 후속 작업입니다.
- 코드 셀 번호를 주석으로 남겼습니다. 자동 변환 과정에서 원래 코드 내부 주석과 Markdown 설명은 보존되지 않으므로 원본을 함께 참고하세요.

## 실행 범위와 남은 작업

프로젝트 루트에서 `python scripts/legacy/inference.py`처럼 실행할 수 있습니다. 실행 전 파일 상단 main 함수 내부의 모델, 체크포인트, 문항 수, 입력 파일과 출력 위치를 확인하세요. GPU 및 각 단계의 기존 의존성이 필요합니다.

이 단계는 실행 환경이나 실험의 정확성을 검증한 완성형 CLI가 아닙니다. 여러 비교 조건을 한 스크립트에서 연속 실행하는 기존 동작도 유지합니다. 출력 파일의 기존 덮어쓰기 동작 역시 남아 있습니다. 학습은 기존 Bash 스크립트를 사용하므로 Windows PowerShell 단독 실행에는 Bash/CUDA 환경 구성이 추가로 필요합니다. 다음 모듈화 단계에서 Python 학습 진입점과 공통 설정으로 대체합니다.

업로드 스크립트는 기존 Hugging Face 저장소 ID를 유지합니다. 직접 실행하면 외부 저장소를 만들거나 변경할 수 있으므로 본인의 저장소 ID로 수정해서 사용하세요. 이번 변환 작업에서는 업로드, GPU 학습, 유료 평가를 실행하지 않았습니다.

기존 차트의 항목 순서, 추론 옵션, 평가 방식은 아직 변경하지 않았습니다. 공통 로더·설정·분석 모듈로 옮길 때 수정합니다.

재생성: `python tools/convert_colab_notebooks.py`. 생성된 7개 파일에 직접 추가한 수정은 재생성 시 사라집니다. `_runtime.py`와 이 README는 생성 대상이 아닙니다.
